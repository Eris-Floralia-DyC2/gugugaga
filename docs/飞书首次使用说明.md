# WS 飞书首次使用说明

WS 可以直接读取飞书群消息，不用安装 MCP、Codex 或 Python。第一次使用需要配置飞书应用，之后通常只需登录授权。

## 1. 准备飞书应用

打开[飞书开发者后台](https://open.feishu.cn/app)，创建“企业自建应用”。如果你没有权限，请找所在组织的管理员协助。

进入应用后，完成下面几项设置：

- 开启“机器人”能力。
- 在“权限管理”中开通下面的用户身份权限。
- 在“安全设置 → 重定向 URL”中填入 `http://127.0.0.1:8001/oauth/callback`。
- 创建版本并发布，完成所需的管理员审批，应用可用范围要包含你的账号。

| 权限 | 用途 |
| --- | --- |
| `im:chat:readonly` | 读取群信息 |
| `im:message:readonly` | 读取消息 |
| `im:message.group_msg:get_as_user` | 以你的身份读取群消息 |
| `offline_access` | 自动续期授权 |

在“凭证与基础信息”中找到 **App ID** 和 **App Secret**，下一步会用到。App Secret 不要放进公开文档或仓库。

## 2. 在 WS 中连接

1. 打开 **管理空间 → 飞书群聊总结 → 设置**。
2. 展开 **首次配置应用（已有连接无需填写）**。
3. 填入 App ID 和 App Secret，点击 **保存应用并连接**。
4. 在打开的浏览器页面登录飞书，同意授权，然后返回 WS。

如果 WS 已经有可用连接，直接点“连接飞书”即可，不必重复填写。

## 3. 选择要读取的群

点击 **获取群聊**，找到并勾选目标群，再点 **测试连接**。

看到“消息读取成功”，就可以继续使用。若提示权限不足，先检查应用权限是否已发布、是否完成审批，再重新授权。能读取哪些消息，由飞书账号权限和群的历史消息设置决定；手动填写群 ID 也不能绕过这些限制。

## 4. 开始总结

先到 **AI 服务**中配置自己的模型接口、模型名称和 API 密钥。只测试飞书消息读取时，不需要配置模型。

回到“飞书群聊总结”，点 **立即总结**可以手动执行；打开 **启用每日总结**后，会按设置的时间自动执行，默认是本机时间 **21:00**。启用总结后，所选群中用于总结的消息会发送到你配置的模型服务。

摘要就在这个页面里，按群名和日期查看，也可以展开“查看依据”核对原文。当天较晚的消息会在后续执行时补采，更新原日期的摘要。

WS 需要保持运行才能按时执行。关闭后重新打开，会补处理遗漏日期。摘要保存在本机，更新程序时请保留原来的 `WS-Private` 文件夹。
