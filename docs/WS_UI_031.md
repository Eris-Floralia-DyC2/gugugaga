# WS 0.3.1 界面更新

消息总结按当前账号联系人资料显示名称：实际可读取的备注优先，其次昵称或群名，最后标识兜底。搜索同时匹配备注及昵称，输入部分名称后按 Enter 展开。选中会话始终置顶，新选中的排在最前；本页普通重绘保留顺序。选择继续以来源与稳定会话 ID 保存，点击顺序仅保留在页面内存。详情中查看完整账号和会话标识，选择会话不改变采集或外发授权。

在“外观与动画 → 个性签名”预览并保存，桌面与工作台即时同步。清空保存隐藏文字；恢复默认还原两个位置原有文案。首次升级未设置签名时保留各自旧文案。签名是最长 500 字符的纯文本，支持中文、英文、标点和表情，长文最多显示 2 至 3 行。设置保存在 PrivateRoot/config/settings.json，随“个人配置”迁移。

更新前从托盘退出，只替换程序文件，保留完整 PrivateRoot。任务、授权、来源 ID 和隐私迁移规则沿用 0.3.0；0.3.1 仍可读取原配置版本 1。回退程序前先退出并备份完整 PrivateRoot；旧版本不认识新增字段时，从本次升级前配置备份恢复 settings.json，勿清除任务或 profile。
