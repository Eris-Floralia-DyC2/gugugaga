# QQ 后台退出与账号切换

在管理空间的“消息接入”中，找到现有 QQ 数据源。

- “启动 QQ 后台”：恢复专用 QQ 环境，必要时本人扫码。
- “退出 QQ 后台并暂停采集”：结束 WS 私密目录内的 QQ 进程，保存消息、任务、登录资料及群选择。重启 WS 仍保持暂停，主动启动才恢复。退出期间无法实时采集新消息。
- “重启 QQ 后台”：清理残留实例后启动，适合进程仍在但采集服务未就绪的情况。
- “切换 QQ 账号”：先退出专用后台，打开登录页。本人登录所需账号后，点击“确认当前账号并连接”，再选择会话。旧账号数据保留；切回旧账号可恢复它的群选择。
- “刷新 QQ 状态”：只检查状态，不启动后台。
- “复制登录 Token”：从当前本机配置读取网页登录 Token，复制到剪贴板。Token 不显示在工作台或操作回执里；环境未准备时会提示准备环境。

“打开 QQ 登录”和“重启 QQ 后台”会打开携带当前 Token 的本机网页，由网页自动验证。若仍要求输入，点击“复制登录 Token”后粘贴。QQ 账号扫码或安全验证仍需本人完成。

“添加数据源”用于首次添加 QQ 入口；已有 QQ 连接时，使用“切换 QQ 账号”。当前仅支持一个活跃的 QQ 账号。以后添加的群沿用同一套采集流程。

网页管理页右上角“退出登录”仅退出网页管理会话，不会结束 QQ 进程，也不会主动释放 QQ 桌面登录。请使用 WS 的退出按钮。

状态会分别显示：尚未准备、后台未运行、主动暂停、等待扫码、采集初始化、进程残留但服务不可用、本机接口凭据异常，以及账号与数据源不一致。接口不可用不等于 QQ 登录授权失效。

当前使用 QCE Shell 6.3.2，后台运行时仍可能与日常 QQ 的同账号登录冲突。本次更新增加生命周期控制，没有更换采集组件。退出会保留已保存消息；离线期间消息能否补齐取决于 QQ 后续同步和本地缓存，不保证完整补采。
