# WS 0.4.0 操作说明

日常流程：在“数据源设置”添加或编辑连接，在“AI 服务”保存服务地址、模型和 API Key，然后进入“会话总结与任务分析”。输入部分备注、昵称或群名并按 Enter，点击会话多选，设置时间范围后执行。

- 选择与有效时间范围自动保存，重启恢复。新选会话立即置顶；点击顺序只在当前页面保留。内部使用来源、账号与会话稳定 ID，同名对象不会混用。
- “生成总结”自动读取所选时间范围、解析可读取的附件、调用 AI 并保存有来源的结果，不创建待办。
- “执行任务分析”使用同一消息索引和附件结果，按既有规则写入原任务库；重复执行不重复导入已处理任务。手动修改、完成和删除保护保持有效。
- 选择本身不请求 AI。取消选择只影响以后按此选择执行的任务，不删除历史或正式待办。执行中的选择是固定快照，此时修改只作用于下次执行。
- 定时规则位于会话页面，明确保存每天的本地时间、回看天数和执行类型。触发时使用当时已保存的会话集合，以及触发时刻向前回看的时间范围。
- 语音只记录类型和来源，并标记“未处理”；不会读取语音文件、转写、下载模型或创建语音确认待办。原有语音相关任务保留。

连接失效时点击“编辑或重新连接”。微信优先复用经当前数据库验证的连接资料；只在缺失或失效时引导保持客户端登录、重新选目录或导入已有连接文件。飞书需要原连接器完成登录后导入，失效时会显示原因。QQ 真实读取尚未实现，不能作为可用平台添加。

停用、删除消息历史、清除凭据和移除数据源位于“管理”，分别显示影响范围；正式任务不因此删除。图片读取修复也在管理中，缺少可验证样本时明确提示。缓存管理只处理解密数据库缓存，不清除 Electron profile、session 或 Local State。

MCP 区域只有“打开 MCP 配置文件夹”。打开的是当前 PrivateRoot/config/mcp，目录内说明启动方式；它不自动启动服务或修改已有 server.json。工作台的总结和任务分析不依赖 MCP 开关。

耗时操作显示真实阶段、已耗时和已取得的数量。未知总量或等待 AI 时使用不定进度；支持安全取消，取消后已经保存的消息和正式任务保留。失败或超时会结束等待并显示原因，可修复后重试。

个性签名仍在“外观与动画”编辑，桌面与工作台即时同步；清空隐藏，恢复默认有效。主题、窗口及多屏行为沿用原实现。
