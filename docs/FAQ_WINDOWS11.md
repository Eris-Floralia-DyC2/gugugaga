# Windows 11 常见问题

| 现象                              | 按实际证据排查                                                                                                                                      |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| PowerShell 不允许运行 npm.ps1     | 使用文档中的 npm.cmd；不需要更改全局执行策略。                                                                                                      |
| npm ci 失败、Electron 没下载      | 确认执行目录和锁文件，保留错误码及下载域名；检查已有代理/网络和对应版本缓存。不要自动全局换源、关安全软件或反复重装。                               |
| 任务可用但“消息处理运行时缺失”    | workerCommand 先查 runtime/ws-worker/ws-worker.exe，再查 .venv/Scripts/python.exe；按部署文档准备其中一种，不能把系统 python 存在当作运行时已准备。 |
| “先构建独立 worker”或已有 runtime | 先构建 worker；已有目录须核对后归档，不覆盖正式运行时。                                                                                             |
| QQ 资源缺失                       | 源码不带 QCE Shell。按 QQ_THIRD_PARTY.md 校验版本、SHA256、源码和许可，只在本机准备。不要复制个人 profile 或私密便携目录。                          |
| QQ 接口失败/账号不匹配            | 分别检查后台启动、网页授权、数据源绑定和当前账号。暂停后需显式启动；网页退出不代表专用 QQ 后台已退出。本人完成扫码/验证。                           |
| AI 401/403、429、5xx              | 分别检查提供商权限、限流/余额、服务状态。核对 Base URL、模型名、超时与协议；不要向 AI 助手粘贴 Key。                                                |
| 没有任务或总结失败                | 先检查来源可用和时间范围，再看采集/附件/模型/校验哪个阶段失败。无依据内容不会自动创建任务，语音和缺失附件需人工核对。                               |
| 密钥无法解密                      | Windows 账户、机器或 profile 可能改变；在本机重新授权，保留原任务和历史。                                                                           |
| 任务文件冲突/损坏                 | 检查 tasks/tasks.json 与最近备份，保留原文件；错误状态下不会自动用空库覆盖。停止其他写入后再恢复。                                                  |
| 窗口不可见/位置不对               | 用托盘显示、重置位置、选择当前显示器；确认不是另一个已运行实例。不要为排错重启 Explorer 或杀所有 QQ。                                               |
| 文件夹很大                        | 分别统计 PrivateRoot、dist、依赖与 Git。QQ 附件/专用客户端和迁移备份可能占主导；逻辑大小不等于可释放物理空间。不要递归跟随联接。                    |
| 安装脚本被策略阻止                | 核对当前策略和组织要求；可以直接使用 .venv Python，普通使用无需执行打包 ps1 或获取管理员权限。                                                      |

日志位于当前 PrivateRoot/logs，smoke 报告在独立测试根的 logs/smoke/smoke.json。日志可能含路径或来源信息，分享前只提取必要脱敏片段。历史验收报告不代表当前环境、真实账号或网络已验证。
