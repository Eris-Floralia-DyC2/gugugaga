# WS 0.3.1 界面更新验收记录

日期：2026-10-21。基于本轮 0.3.0 成果继续修改；保留原任务库、来源 ID、授权范围及 PrivateRoot，不另建系统。

## 变更

- 微信名称目录读取当前账号 contact 表实际可用的 remark、nick_name。私聊备注优先，群聊使用实际读取到的本账号群备注；不可读取时回退昵称/群名，再回退稳定标识。两种名称同时可搜索，不推测备注。完整标识收进“会话详情”，同名项辅以账号和来源尾号区分。
- 输入部分备注、昵称或群名，按 Enter 展开；无结果有提示。处理组合输入状态、isComposing 和 229 键码，搜索不会调用总结。
- 使用稳定的来源/会话键更新选中集合，移动现有 DOM 节点；新选会话立即置顶并保留焦点。计数、单选、多选、取消选择同步；页面内点击顺序跨普通重绘和状态更新保留，页面重载后只恢复选择集合。
- “外观与动画”新增签名预览、保存、恢复默认。纯文本支持中英文、标点和表情；清空保存隐藏；长文限制行数。旧配置未设置签名时保留两处各自原始文案；保存自定义内容后两处同步。
- 签名存于 PrivateRoot/config/settings.json 的 appearance.signature。null/缺省为原始默认，空字符串为隐藏，其他字符串最长 500 个 UTF-16 代码单元。旧配置版本仍为 1，读取时补充缺省值，随个人配置迁移。
- 构建及 worker 的模型依赖缓存和日志显式定位 PrivateRoot，避免使用用户目录的依赖默认缓存位置。

## 更新和回滚

退出 WS 后解压完整程序到普通可写目录，保留完整 PrivateRoot；数据路径解析、干净包与私密迁移包分离规则沿用部署说明。正式桌面程序已按此方式替换，保留了原私密根入口。

旧程序及本轮源码、任务和 settings.json 基线备份保存在本人 PrivateRoot/development/ui-031。回退时先从托盘退出，恢复旧程序；若使用不识别签名字段的旧版本，恢复本轮 settings-before.json 到 PrivateRoot/config/settings.json。勿清空任务、授权、profile、session 或 Local State；不要把隔离测试数据覆盖到正式根目录。
