# Windows 11 使用指南

## 首次使用和核心操作

从托盘打开管理窗口。任务页新增标题、备注、计划日期、可选截止日期及优先级；组件中可完成/撤销，管理窗口中编辑和删除。外部同时修改任务文件时，过期界面提交会被拒绝，请刷新核对后重试。任务文件损坏时保留最近有效数据，不要用空文件覆盖。

普通未完成任务的截止日期晚于或等于系统今天时，显示在“今日待办”，包含截止日期当天。到截止日期次日，计划日期已过去的未完成任务进入“历史未完成”。没有截止日期时按计划日期分组；每日重复任务仍按各天实例分组。显示分组不会改写原计划日期、截止日期或复制任务。

外观页调整主题、背景、个性签名、透明度、动效；双击日期区域折叠/展开。窗口设置支持桌面模式、置顶、多屏移动和位置重置。锁屏、电池、多屏和 Explorer 状态依赖 Windows 实际行为，遇到异常先使用托盘恢复显示或重置位置。

“数据源设置”连接微信/QQ/飞书；“AI 服务”保存模型与凭据；“会话总结与任务分析”保存会话和时间选择。语音不解析；附件缺失会标为不完整，指定群可能生成每日人工确认提醒。清空结果消息只移除展示，不清除任务、消息库或处理进度。QQ 暂停、退出及切换账号详见 QQ_SESSION_051.md，登录和账号确认必须由本人完成。

默认开机自启配置为 true，但只有打包后的程序才会注册 Windows 用户级自启，源码开发模式不注册。不需要时到程序设置关闭；便携目录移动后重新检查自启路径。

## 全局快捷键 Ctrl+T

WS 运行后，无论当前使用哪个程序，第一次按 Ctrl+T 都会显示 WS 并切换为始终置顶；再次按下会隐藏，再按则重新显示。这里只收起桌面小组件，托盘、任务与已启用的后台计划继续运行。窗口设置保留这次选择的置顶模式。

手动从托盘收起后，再按 Ctrl+T 也能呼出。真正退出 WS 后会释放快捷键，不会继续拦截其他应用的 Ctrl+T。如果快捷键被别的程序占用或系统拒绝注册，“窗口与显示器”页面会显示未启用原因；释放占用后重启 WS 即可重试，原有托盘入口仍可使用。

## 数据位置、备份与更新

开发时默认 `<项目根目录>\WS-Private`，便携包默认 `<WS.exe 所在目录>\WS-Private`；绝对 `WS_PRIVATE_ROOT` 优先。该目录包含任务、配置、凭据、账号、消息、附件、主题和运行缓存，应当整体视为私人数据。

退出托盘中的 WS 和该实例专用 QQ 后台后再备份。需要完整同机恢复可复制整个 PrivateRoot 到本人管理的安全位置；不要复制到公开仓库。跨设备优先使用程序设置中的私密迁移导出/导入；导出包仍包含任务/设置/历史，属于私人资料，默认不含凭据及浏览器 profile/session。新位置/新账户可能需重新授权。完整根目录迁移会保留旧副本，可能明显增加空间。

更新前保存源码改动并备份 PrivateRoot；把新源码或程序放到新目录，阅读迁移说明，再使用同一已备份的数据目录。不要覆盖运行中的 EXE/DLL；不要用干净包里的空目录替换旧 PrivateRoot。不要通过 `git reset --hard` 丢弃本地修改。

## 空间、卸载和数据清理

QQ 专用客户端、QCE 资源及附件、历史开发/迁移备份可能很大。WS 的缓存清理只覆盖其管理的缓存，不能据此断定 QQ 资源目录可全部删除。先量大小和用途，不要跟随目录联接。私人附件、历史及回退材料默认保留。

卸载：先关闭开机自启，退出 WS 及其专用 QQ 后台，再移除程序或源码目录。若 PrivateRoot 位于其中，先迁走并验证备份。只移除程序不会自动抹除外部 PrivateRoot。确认不再需要私人数据、备份及登录状态后，才由本人单独删除对应目录。DPAPI 仅保护部分凭据，聊天库和导出并非整体加密。删除数据不会撤销第三方服务已收到的内容，也不等同于安全擦除或账户凭据撤销。
