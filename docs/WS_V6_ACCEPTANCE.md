# WS 0.3.0 本次验收报告

日期：2026-10-21，Asia/Shanghai。本报告仅记录本轮重新执行的检查；旧 V6 报告已归入本人 PrivateRoot/legacy，不沿用旧结论。

## 项目与交付

通过 Windows 系统桌面目录定位现有 WS 主项目。保留原 Electron 桌面小组件、管理窗口、主题、双屏与 DPI 逻辑、任务 JSON 库、任务导入接口和窗口设置。正式程序仍在主项目 dist/WS/WS.exe；正式数据统一到主项目 WS-Private，程序默认 WS-Private 入口联接此目录。公开包采用独立允许清单构建，不混入正式数据。

本轮增加统一数据源配置 v2、可视化重设入口、源与账号绑定账本、独立外发范围、会话时间范围、按源定时、PrivateRoot 解析、干净部署、私密导出/导入、完整根目录迁移及工作台消息总结。

## 模拟与故障注入通过

18 项 Node、39 项 Python 测试通过。以下使用构造数据，不能等同新的真实平台样本：

- 数据源停用、移除、换账号、凭据解密失败均保留任务；同账号目录后缀变化保留旧来源与任务身份，另一账号分配新 ID；移除后重新添加同账号可恢复原命名空间。
- 消息、游标、WAL、内容指纹、缓存锁和 LRU；重复消息与任务导入、用户修改/完成/删除保护；六种文档正文、图像格式和 SILK 解码。
- 总结多会话分别处理、同名对象区分、改名仍保留稳定选择、空范围、未授权不读正文也不发请求、外来消息 ID/编造引文拒绝、未转写语音与缺失附件说明。
- 私密迁移包版本、路径越界和篡改拒绝；注入中途失败后回滚；迁移后的未完成分析批次可正确确认，不因路径重定位重复分析。
- 完整 PrivateRoot 同机换目录，包含 profile/Local State 的构造文件逐字保留，原根备份也进入新 PrivateRoot/backups；真实目录联接切换通过。
- 每日调度、跨天和关机后的补采采用时钟分支测试，本轮未等待下一个自然日，也未模拟真实断电。
