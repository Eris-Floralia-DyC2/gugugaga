# 飞书每日群聊总结（WS 0.5.6）

在管理空间左侧打开“飞书群聊总结”。连接飞书，按群名选择需要总结的群，再启用每日总结。默认本机时间 21:00；修改时间或暂停开关后自动保存。群聊选择完成后点击“保存设置”，也可以直接点击“测试连接”或“立即总结”。

## 连接与首次授权

优先复用 WS 已有飞书凭据，或本机 Codex 注册的 `feishu_group_intelligence` 连接。只读取配置定位到的本地连接器，不另启 MCP 服务。有效授权迁移到当前 WS 的 PrivateRoot 后使用 Windows 当前用户 DPAPI 加密保存。

没有可用用户授权时，WS 会用系统浏览器打开飞书 OAuth 页面。本机回调监听仅在授权过程中开启，10 分钟后关闭。应用后台须允许 `http://127.0.0.1:8001/oauth/callback`。如果本机其他飞书授权服务占用了该端口，先结束该授权服务再连接。

没有可复用应用时，展开“首次配置应用”：只需保存一次 App ID 和 App Secret。飞书应用仍需要开启机器人能力、申请和发布权限，以及租户管理员批准；客户端无法免除平台要求。这里的“开启机器人能力”与“把机器人加入某个群”是两项不同操作。

使用用户身份，只申请 `im:chat:readonly`、`im:message:readonly`、`im:message.group_msg:get_as_user` 和 `offline_access`。用户授权到期前自动刷新；刷新失败时可重新连接。不同 Windows 账号或其他电脑需要重新授权，便携迁移不复制可复用凭据。

## 自然日归档与恢复

- 每个账号、群 ID 和本机自然日只有一条摘要记录。群改名不会改变记录键。
- 21:00 首次执行保存当天截至执行时刻的初步摘要。下一次执行先补采前一天剩余消息，更新原日期记录。
- 修改时间不改变自然日边界。处理游标和消息 ID 去重用于接续，午夜消息归入新一天。
- WS 运行时复用程序每分钟调度检查；启动、休眠恢复或联网恢复后补执行。程序关闭期间不运行独立服务。
- 多天未运行时逐日恢复；某群失败不阻塞其他群。失败后约 5 分钟重试，已经完整处理的日期直接复用。
- 第一次添加群从当天开始。移除群会保留本地摘要，重新选择后从已保存日期恢复。
- 没有新消息不重复调用模型；没有文字时只保存采集状态并提示未解析内容。
- 采集成功与 AI 生成成功分别记录。模型更新失败保留旧摘要，下次可以直接使用已采集上下文重试。

所有恢复均受飞书官方接口当前可见范围、群保密设置、用户权限和历史消息可见性限制。“已补全”表示当前可访问接口的自然日时间窗口已采集完成，不保证恢复接口本身不可见的消息。

## 消息与摘要

复用现有飞书官方 OpenAPI 客户端，逐页读取群消息；对普通群话题额外逐页读取话题回复，并保留根消息、父消息和话题 ID。为发现旧话题中的新回复，每次群处理开始会扫描可访问的群历史根消息，仅保留内存中的话题 ID。大群的首次扫描可能较慢。

复用 WS 现有模型服务和总结附加提示词。长消息分批提取带原消息依据的要点，再合并去重；返回内容必须通过来源 ID 和逐字引文校验。附件复用既有文档解析，图片和语音未解析时明确标记，不推测内容。

在“每日总结”中按群名和日期展开查看主要内容、通知、结论、后续事项、时间和关注信息。点击“查看依据”可核对短原文、消息时间和原消息 ID；“查看更早的摘要”逐页读取本地历史。

该入口只生成摘要，不调用任务导入、任务分析或每日确认任务逻辑。原有“会话总结与任务分析”的行为不变。

## 存储与更新

设置保存在 `PrivateRoot/config/feishu-daily.json`，摘要和处理进度在 `PrivateRoot/databases/feishu-daily.sqlite3`。待补全日期临时保留整理后的上下文；自然日采集完成且摘要成功后删除该日期原始上下文，仅保留摘要、短引文和来源 ID。临时下载的附件在提取后清除。历史摘要不会无限复制同日期版本。

更新便携程序时保留原 `WS-Private` 目录。现有“程序与数据”迁移会包含新设置和摘要数据库；授权凭据仍需要在目标 Windows 账号重新连接。
