# WS 0.5.2 使用说明

双击桌面小组件的日期区域任意位置可以折叠日期；再次双击“展开日期”区域即可恢复。折叠状态会保存，重启后继续生效。也支持聚焦后按 Enter 或空格。原背景、主题、签名和任务库保留。

桌面左下角不再显示消息同步或分析异常。数据源连接和分析失败的具体原因仍可在工作台相应页面查看。会话详情用平台、账号名称、会话名称和“消息 N”表示来源，不再展示内部消息编号。

右下角操作提示在执行期间保持显示，成功、失败或取消后保留 5 秒，随后自动隐藏；需要时仍可在原页面查看结果。

会话总结页面默认使用系统本地时间：昨天 00:00:00 到今天 23:59:59。默认范围随系统日期更新；手动修改时间后保留自定义范围。实际采集截止于执行时刻，不会把今晚的未来时间写成已采集进度。

新增选择会话后，旧会话已完成的任务分析不会重复发送。以后执行时自动分析该会话新增或发生变化的消息。总结按会话保存结果：消息和提示词等条件未变化时复用已有结果；变化的会话重新生成该会话总结，单次最多使用该范围内最近 200 条消息。新增会话、微信和 QQ 使用同一套处理规则，不按群名写特殊逻辑。

任务分析要求每个来源都有可核对的原文。模型使用简短消息编号，系统核对后恢复正式来源；核对失败时仅针对同一批消息修正一次。仍有问题的候选任务进入人工核对，其他有依据的任务继续处理，不会把无法判断的消息直接标为“无有用信息”。网络或授权失败仍会明确报错，并保留缓存。

QQ 使用随程序配置的 QCE 6.3.2。插件齿轮显示“没有配置”表示它没有提供 NapCat 插件配置表单；采集和账号控制在 WS 的数据源设置进行。管理页显示的旧版本可能来自缓存，请以 WS 实际接口检测为准；勿用旧插件替换已验证组件。登录 Token 的自动填入与复制按钮继续保留。

升级时先真正退出 WS，保留完整 WS-Private，再更新程序文件。干净程序包不含任何个人任务、聊天消息、账号状态或 API 密钥。QQ 会话控制见 QQ_SESSION_051.md；构建方法见 BUILD_050.md。
